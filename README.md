## 它解决什么

保存角色身份和声线；每期重新研究参考、设计故事与剪辑，不把上一条改几个词继续用。支持9∶16双角色视频，默认先预览、确认后导出。

## 拟交付内容

## 购买前需要了解

这是供AI代理使用的工作流指令包，需要用户提供参考内容和角色素材，并配置兼容的制作工具。它不是独立桌面软件，也不是安装后即可保证一键出片的渲染器。

制作路线使用 HyperFrames、Python/FFmpeg 与 Qwen3-TTS。使用者需要可运行技能的AI工具；AI服务费用、算力、第三方工具及素材授权不包含在售价里。支持的平台与最低硬件配置将在独立环境验证后公布。

不会承诺播放量、涨粉或收入；不同参考、表演和素材会产生不同结果。
